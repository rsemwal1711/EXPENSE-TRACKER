# 💰 TrackMyCash — Smart Expense Tracker & Budget Manager

> Track your expenses, manage budgets, and understand your spending — all in one clean dashboard.

🔗 **Live Demo:** [expense-tracker-frontend-8171.onrender.com](https://expense-tracker-frontend-8171.onrender.com/)
📂 **Repository:** [github.com/rsemwal1711/EXPENSE-TRACKER](https://github.com/rsemwal1711/EXPENSE-TRACKER)

---

## ✨ Features

- ➕ **Add, edit, and delete expenses** with category tagging
- 📊 **Analytics dashboard** — total spent, average per expense, highest single expense, monthly trends
- 🥧 **Category breakdown** with interactive pie & bar charts
- 📈 **Income vs. Expense tracking** with monthly comparison graphs
- 🧾 **Receipt upload & management** — attach, view, and organize receipts by month
- 🎯 **Savings goals** — set and track financial targets
- 🌙 **Dark-themed, responsive UI** for a clean user experience

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn
- MongoDB (local or Atlas connection string)

### 1️⃣ Clone the repository
```bash
git clone https://github.com/rsemwal1711/EXPENSE-TRACKER.git
cd EXPENSE-TRACKER
```

### 2️⃣ Setup Backend
```bash
cd backend
npm install
```
Create a `.env` file in `backend/`:
```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```
Run the backend:
```bash
npm start
```

### 3️⃣ Setup Frontend
```bash
cd frontend
npm install
npm run dev
```

The app should now be running locally 🎉
